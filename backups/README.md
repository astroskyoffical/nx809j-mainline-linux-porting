# Phone backups

Dated captures stay inside this project at the owner's request. Do not overwrite
an earlier capture or commit raw device data to Git. Each capture records exact
scope, device-side and host SHA-256 hashes, and errors or consistency limits.

Partition readback is not a personal/app-data backup or proof of successful
recovery. Running-system captures of changing partitions are not coherent offline
snapshots. Never restore another phone's identity, calibration, or key material.

No automatic restore or flash command is provided.
