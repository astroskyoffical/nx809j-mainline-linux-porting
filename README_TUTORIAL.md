# KVM Virtualization Tutorial - RedMagic 11 Pro

This guide explains how to manage and verify native virtualization on your device.

## 📂 Folder Contents
1.  **Activate_KVM.bat**: Script to enable KVM on Android (requires root via ADB).
2.  **Verify_KVM.bat**: Script to check if the Gunyah Hypervisor is active.
3.  **README_TUTORIAL.md**: This document.

## 🚀 How to use
If you need to re-enable virtualization (e.g., after a factory reset):
1.  Connect your phone to your PC with USB Debugging enabled.
2.  Run the `Activate_KVM.bat` file.
3.  The device will reboot.
4.  After booting, run `Verify_KVM.bat` to confirm.

## ⚙️ Technical Details
*   **Hypervisor:** Qualcomm Gunyah (Type-1).
*   **Mode:** pKVM (Protected KVM).
*   **Interface:** Android Virtualization Framework (AVF).
